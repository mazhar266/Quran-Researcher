# Quranic Arabic Corpus — morphological annotation

`quran-morphology.txt` and `morphology-terms-ar.json` come from
[mustafa0x/quran-morphology](https://github.com/mustafa0x/quran-morphology),
an Arabic-script fork of **Quranic Arabic Corpus morphology v0.4**
(Copyright © Kais Dukes, 2011).

* Upstream source: <http://corpus.quran.com>
* Licence: GNU General Public License

The corpus terms require that any application using this annotation clearly
indicates the source and links to <http://corpus.quran.com> so users can track
changes. The app does this on its attribution screen; keep that in place.

Note the project also ships GPL data (Arramooz), so the combined distribution
is already GPL-encumbered — check this before any proprietary relicensing.
