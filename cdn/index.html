Content CDN

This endpoint serves downloadable data assets for Hikmah applications. It hosts the optional content modules of Quran Researcher — tafsir libraries, a classical Arabic dictionary, and muṣḥaf page fonts — delivered on demand when a user chooses to install them inside the app.

How it works

  1. Assets are addressed by versioned paths; older app releases keep working when new data is published.
  2. Every download is verified against published sizes and SHA-256 digests before it is used.
  3. These are plain static files — no accounts, no tracking, no analytics. The app downloads only what the user asks for.
